- 全体は通常ファイル1,994件、元データ約499MB。gzip形式の暗号化アーカイブは419,658,770バイト。全ファイルを保持したままZstandardで再圧縮した転送用ファイルは241,967,610バイト。

- PCの保存先は `saas/workspace/vps-import-20260918/private/`。Git対象外で、Windowsのアクセス権は現在のユーザーとSYSTEMに限定。
