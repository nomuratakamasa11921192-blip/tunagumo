# ツナグモ サイト改修 指示書

**Claude Codeに渡すための仕様書。**
既存の `tsunagumo.pages.dev` を、SaaS事業に合わせて全面的に作り直す。

---

## 前提

| | |
|---|---|
| 主力商品 | **業種特化AI SaaS**（月5万円の一律プラン。AI利用料は別途、顧客が自分でAnthropic社と契約） |
| 入口 | **2週間無料トライアル** |
| 対象 | **不動産** に一本化(2026-08-31)。人材紹介／士業／Web制作・広告の`/for/*`ページとconfigは削除せず温存、リンクのみ外している。将来の横展開(自動車・美容クリニック等)時に再利用する |
| スポット案件 | HP制作・動画編集は残すが、**主役にしない** |

**現在のサイトは「人が作業する受託」の構成。** これをSaaS中心に組み替える。

---

## 【最重要】書き方の原則

### ① AIを主語にしない

```
❌ 「生成AIを活用した業務効率化」
⭕ 「求人票の作成が、2時間から30分に」
```

**顧客が買うのは時間。AIは手段。**

### ② 業種を明示する

```
❌ 「中小企業・個人店の皆さまへ」
⭕ 「不動産・人材紹介・士業の事務作業を減らします」
```

**4業種以外の人が来ても契約にならない。** 絞ったほうが、来た人に刺さる。

### ③ 言い切らない（法的リスク）

| ❌ | ⭕ |
|---|---|
| 「法令違反を100%防ぎます」 | 「違反しやすい表現を自動で検出します」 |
| 「データは国内で完結」 | 「保管は国内。生成処理は海外のAPIを経由します」 |
| 「誰でも使えます」 | 「AIの知識は不要です」 |
| 「必ず売上が上がります」 | 「作業時間の短縮が見込めます（試算値）」 |

## `/terms` 利用規約

**最低限、以下を含める。** ※専門家の確認を推奨

- サービス内容と提供範囲
- **生成物の内容に関する免責**（誤情報、法令適合）

- 取得する情報
- **利用目的**
- **第三者提供・委託先の明示**（Anthropic社、さくらインターネット）
- **海外への移転について**（AI処理が海外で行われること）
- 保存期間
- 開示・削除の請求方法
- 問い合わせ先

## `/law` 特定商取引法に基づく表記

**オンラインで有料サービスを提供する場合、必須。**

- 販売事業者名
- 責任者
- **所在地・連絡先**（個人事業の場合、開示請求があれば遅滞なく提供する旨でも可）
- 販売価格
- 支払方法・時期
- サービス提供時期
- **返品・キャンセルについて**

**未成年の場合の注記も検討する。**

# 実装の指示（Claude Code向け）

## 技術

- 既存の Cloudflare Pages をそのまま使う
- 静的サイトでよい（フォームは外部サービス or 簡易API）
- **スマホ優先**（経営者はスマホで見る）

## デザイン

- 既存のトーン（落ち着いた配色、余白多め）を維持する
- **数字を大きく見せる**（月20〜40時間、月5万円）
- CTAボタンは各セクションの末尾に配置

## 作る順番

```
1. /trial          ← DMのリンク先。最優先
2. /              ← トップ
3. /for/real-estate、/for/recruiting  ← 主力2業種
4. /pricing、/faq
5. /for/legal、/for/web-agency
6. /about、/spot
7. /terms、/privacy、/law  ← 公開前に必須
```
