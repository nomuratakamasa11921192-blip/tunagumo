# AI × 各領域 事業性分析

> **【使用時期】新しい事業アイデアが浮かんだとき。**
> 末尾の「5つの確認」を通せば5分で判断できる。**同じ検討を繰り返さないための記録。**

**作成：2026年8月**
**目的：** 事業の方向に迷ったとき、同じ検討を繰り返さないための記録。
**前提：** 個人（高校生・資本ほぼゼロ・埼玉県春日部）が今から参入する場合の評価。

---

## 評価の4軸

| 軸 | 見るもの |
|---|---|
| **文書量** | AIで削減できる作業が構造的に発生し続けるか |
| **予算** | その業界に払う金があるか |
| **参入障壁** | 自分が入れるか／入った後に守れるか |
| **決裁速度** | 契約までの時間 |

**個人が最も重視すべきは「予算」と「決裁速度」。**
社会的意義が大きくても、予算がなく決裁が遅い領域は、個人事業として成立しない。

---

# S級：今すぐ着手すべき

## AI × 士業（社労士・行政書士・税理士）

| | |
|---|---|
| 単価 | **月10〜30万円** |
| 削減時間 | 月15〜25時間 |
| 決裁 | 早い（所長の一存） |

**なぜ強いか：**
- 士業は**時間単価が高い**（1時間1〜3万円）。削減価値が大きい
- 文書作業が業務の中心
- **業務独占の理解が参入障壁になる。** 何も知らない業者は提案を外す

**参入の鍵：**
```
❌ 「書類作成を自動化します」→ 業務独占への無理解を露呈。即失注
⭕ 「書類作成は先生方のお仕事です。私がお手伝いできるのは
    顧問先へのご案内文や社内資料の整理です」
```

**この一言が言えるかどうかで、信用が決まる。**

**将来性：** 高い。士業の高齢化と、事務員の採用難で、効率化の需要は伸び続ける。

**リスク：** 各士業法の業務独占。**必ず有資格者の最終確認を運用に組み込む。**

---

## AI × 不動産（賃貸仲介・売買）

| | |
|---|---|
| 単価 | **月8〜15万円** |
| 削減時間 | **月20〜40時間**（全業種で最大級） |
| 決裁 | 早い（社長の一存） |

**なぜ強いか：**
- **物件数だけ文章が必要**＝需要が構造的に発生し続ける
- 1物件につき紹介文・広告文・メールが必要で、それが毎月何十件も
- 地場の中小業者が多い（春日部は住宅地）

**参入の鍵：** 不動産の表示に関する公正競争規約を理解していること。
「完全」「万全」を使った紹介文を送った時点で、プロではないと見抜かれる。

**将来性：** 中〜高。**大手は内製化を進めるので、狙うのは地場の中小。**

**リスク：** 宅建業法、公正競争規約。**サンプル段階から規約を守る。**

## AI × 人材紹介・派遣

| | |
|---|---|
| 単価 | **月8〜15万円** |
| 削減時間 | 月20〜35時間 |
| 決裁 | 早い |

**なぜ強いか：**
- **スカウト文は1人ずつ違う文面を大量に書く**＝AIの最適領域
- 人手不足で**業界自体が伸びている**
- 求人票・スカウト・候補者連絡・企業への推薦文と、文書の種類が多い

**将来性：** 非常に高い。労働人口が減るほど、人材業界の需要は増える。

**リスク：** 職業安定法（性別・年齢の限定表現、虚偽の労働条件表示）。

---

## AI × 映像・動画編集

| | |
|---|---|
| 単価 | **月5〜10万円**（1本1.2〜3.5万円） |
| 競合 | **少ない** |

**なぜ強いか：**
- 動画需要は増え続けている
- **手作業の編集代行は多いが、自動化している事業者が少ない**
- ffmpegパイプラインを既に保有＝**先行者利益がある**

**将来性：** 高い。

**注意：** 生成AI動画（Higgsfield等）は従量課金が重い。**素材ありの編集に限定する。**

## AI × AI（生成物の検証・品質保証）

| | |
|---|---|
| 市場 | **今から立ち上がる** |
| 単価 | 高い（企業向け） |

**なぜ有望か：**
```
AIを使う企業が増える
　↓
「この出力、本当に正しい？」という不安が生まれる
　↓
検証・法令チェック・出典確認の需要
```

**AIが普及するほど、検証の需要が増える。** 構造的に伸びる。

**具体的な形：**
- AI生成コンテンツの景表法・薬機法チェック
- 出典の裏取り代行
- AI利用ガイドラインの策定と監査

**F3（AI組織）のQA監査が、まさにこれ。** 仕様書は既にある。

**将来性：** 非常に高い。ただし**市場が立ち上がるのは1〜2年後。**

# 補論：B2Cアプリ構想の評価（コミュ障克服AI・垢抜けAI等）

**「アプリを作って個人に売る」という発想が出たときの判断基準。**

## 共通の壁：必要なユーザー数

```
月500円のアプリ
→ 事業として成立させるには 1万人必要
→ 広告費なしで1万人は、ほぼ不可能
→ 広告を打つと 1人獲得に500〜2,000円
→ 回収に1〜4年
```

**資本がないと、B2Cアプリは成立しない。** これが最大の壁。

| | B2Cアプリ | 今の事業（B2B） |
|---|---|---|
| **必要な顧客数** | **1万人** | **10〜20社** |
| 集客手段 | 広告（資本が要る） | **DM（今日から）** |
| 単価 | 月500円 | 月5〜25万円 |
| 開発期間 | 2〜3ヶ月 | **0（準備完了）** |

**「1万人集める」と「20社に売る」は難易度が桁違い。**

## 個別評価

### コミュ障克服AI（✕ 個人事業では避ける）

| | |
|---|---|
| 需要 | ある |
| 競合 | 会話練習アプリ多数。**ChatGPTの音声モードで代替される** |
| **最大の問題** | **メンタルヘルスに近接する** |

**「コミュ障」を扱うと、社交不安障害の当事者が使う。**

- 効果を保証できない
- 悪化した場合の責任を負えない
- 医療でないことを明示する必要がある

**個人事業で扱うにはリスクが重い。**

**成立しうる形（限定的）：**
```
就活生向けの「面接練習」
→ 「コミュ障克服」ではなく目的を絞る
→ 成果が測りやすく、責任範囲も明確
```

### 垢抜けAI（△ B2Cは厳しい／B2Bなら成立）

| | |
|---|---|
| 競合 | パーソナルカラー・骨格診断アプリは飽和 |
| 単価 | 低い（月数百円） |
| **リピート** | **しにくい**（1回診断したら終わり） |

**「商品に繋げる」＝アフィリエイト or 物販。**
成約率1〜3%、単価数百円。**やはり万単位のユーザーが必要。**

## 抜け道：同じ技術をB2Bで売る

**売り先を変えると、単価が100倍になる。**

| アイデア | B2C | **B2B** |
|---|---|---|
| 垢抜けAI | 月500円 × 1万人 | **美容室・アパレル向け**<br>接客カウンセリング支援、顧客別提案文、SNS投稿<br>**月3〜8万円 × 10〜20店舗** |
| コミュ障克服 | 月500円 × 1万人 | **企業の研修部門向け**<br>新人研修のロープレ相手、営業トーク練習<br>**月5〜15万円 × 10社** |

**個人に月500円を1万人ではなく、企業に月5万円を10社。**
集客コストが桁違いに低い。

## 【重要】B2Bにするなら、今の事業と同じ動きになる

```
垢抜けAIをB2Bで売る
　↓
営業先：美容室・アパレル
　↓
やること：DMを送る → SNS投稿代行を提案 → 月3〜8万円
　↓
これは今の事業（F2：業務代行）そのもの
```

**新しくアプリを作る必要がない。** 既存のメニューで売れる。

**アプリを作るのは、DMで需要が確認できてから。**
「美容室にSNS投稿代行を提案したら、10社中5社が興味を示した」
→ そのときに初めて、専用ツールを作る意味が出る。

## 判断のまとめ

| | 判断 |
|---|---|
| コミュ障克服AI（B2C） | **✕ やらない。**メンタルヘルスのリスク |
| **コミュニケーション研修（B2B）** | **○ 1年後。**下記参照 |
| 垢抜けAI（B2C） | **✕ やらない。**1万人が必要 |
| 垢抜け系のB2B | **○ ただし今の事業のメニューで足りる。**新規開発は不要 |
| 研修向けロープレ | **○ 1年後。**企業への信用ができてから |


## AI × コミュニケーション（B2B）の詳細

**B2Cは避けるが、B2Bなら成立する。**

```
【企業の研修部門向け】
・新人研修のロープレ相手（営業トーク、クレーム対応）
・面接官の練習
・接客の練習
月5〜15万円
```

**B2Cとの決定的な違い：**

| | B2C（コミュ障克服） | B2B（研修） |
|---|---|---|
| 使う人 | **社交不安の当事者かもしれない** | **業務スキルを上げたい社員** |
| 目的 | 曖昧（「克服」の定義がない） | **明確**（営業成績、接客品質） |
| 責任 | 悪化したときに負えない | **業務研修なので範囲が明確** |
| メンタルヘルスのリスク | **高い** | 低い |

**「克服」を売らない。「練習環境」を売る。** これで責任の範囲が明確になる。

**課題：**
- 研修部門があるのは社員100人以上の企業
- **決裁が遅い**（部門長→人事部長→役員）
- **実績が要る**（高校生では入り口がない）

**着手：1年後。** 今の4業種で実績を作り、法人への信用ができてから。

# ブルーオーシャンの作り方

## 「AI × 業種」の2つ掛けでは差別化にならない

**誰でも思いつく。** 実際、AISAKUも大塚商会も同じ場所にいる。

## 3つ掛けると独自になる

```
AI × 不動産 × 地方       ← 大手が来ない
AI × 士業 × 業務独占の理解 ← 参入障壁が高い
AI × 映像 × 自動化パイプライン ← 既に保有
AI × 語学 × 技能実習生    ← 春日部の地域性
AI × 塾 × 現役受験生の視点  ← 本人固有
```

## たかまさくんの3つ目の変数

| 変数 | 使える場面 |
|---|---|
| **高校生** | 話題性、若さへの信頼、応援されやすさ |
| **春日部・埼玉東部** | 地場の中小、製造業、外国人労働者 |
| **既存スキル** | ffmpeg、Claude Code、LangGraph |
| **現役受験生** | 塾・教育業界での現場感 |

**この4つのどれかを必ず掛ける。** 掛けないと、AISAKUと同じ土俵になる。

# 迷ったときの確認

**新しい領域を検討したくなったら、この5つを自問する。**

1. **今の事業で、何件納品した？**
   → 0件なら、まだ判断材料がない
2. **その領域に予算はあるか？ 決裁は早いか？**
   → 社会的意義と事業性は別
3. **3つ目の変数（高校生／春日部／既存スキル）を掛けられるか？**
   → 掛けられないなら、大手と同じ土俵になる
4. **B2CかB2Bか？**
   → B2Cなら**1万人**、B2Bなら**10〜20社**。資本がないならB2B一択
5. **今の事業のメニューで売れないか？**
   → 売れるなら、新規開発は不要（→ 補論）

**新しい領域を探す時間は、DM 200〜300件分に相当する。**
その時間で顧客が1〜2社決まる可能性がある。

**領域の検討は「今の事業が回らないと確認できてから」。**
