# ツナグモ サイト

**このファイルは `~/tsunagumo/website/CLAUDE.md` に置く。**

---

## このプロジェクト

事業サイト。Cloudflare Pages で公開している。

**仕様書：`../docs/website_spec.md`**（作業前に必ず読む）

---

## 技術

- 静的サイト（HTML / CSS / 最小限のJS）
- ホスティング：Cloudflare Pages
- **スマホ優先**（顧客の経営者はスマホで見る）

---

## デザイン

- **既存のトーンを維持する**（落ち着いた配色、余白多め、明朝系の見出し）
- **数字を大きく見せる**（月20〜40時間、月3万円）
- CTAボタンは各セクションの末尾に配置
- ゼロから作り直さない。既存のCSSを活かす

---

## 絶対に守ること

- **すべてのCTAは `/trial` に繋げる**
- 「絶対」「必ず」「100%」「国内完結」を使わない
- 法令チェックには必ず注記を付ける
  ```
  ※検出は補助機能です。最終的なご確認は貴社でお願いしています。
  ```
- トライアルページに以下を明記する
  ```
  ※ 生成された文章は、必ず内容をご確認のうえご利用ください。
  ※ 文章の生成には海外のAIサービス（Anthropic社）を利用しています。
  　 個人情報を含む内容の入力はお控えください。
  ```
